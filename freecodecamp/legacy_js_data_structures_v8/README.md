# **Legacy JavaScript Algorithms and Data Structures V8**

This repository contains my work through the **Legacy JavaScript Algorithms and Data Structures Certification (V8)**.  
The certification teaches the foundations of JavaScript—covering everything from basic syntax to advanced algorithmic thinking—through hands-on, project-based learning.

Developers use **HTML** and **CSS** to create the content and styling of a page, while **JavaScript** adds interactivity and logic. This curriculum focuses on mastering JavaScript fundamentals and applying them in real-world scenarios.

---

## **📚 What This Repository Includes**

The repository tracks my progress across many interactive lessons, practice challenges, and certification projects.  
Throughout this course, I worked with:

- **Core JavaScript fundamentals**  
  Variables, data types, arrays, objects, loops, functions, conditionals, and the DOM.

- **Programming paradigms**  
  Object Oriented Programming (OOP), Functional Programming, and recursion.

- **Algorithmic thinking**  
  Sorting, iteration patterns, problem-solving, and data transformations.

- **APIs & browser features**  
  Fetch API, Promises, async/await, and localStorage.

- **Debugging techniques**  
  Understanding JavaScript errors and improving code reliability.
