# 📝 Todo App (Vanilla JavaScript)

A simple and interactive Todo application built using **HTML, CSS, and JavaScript**, with support for creating, editing, deleting, and persisting tasks using **localStorage**.

---

## 🚀 Features

- ✅ Add new tasks  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks  
- 💾 Persistent storage using `localStorage`  
- 🧠 Smart form handling (unsaved changes confirmation)  
- 🔒 Input sanitization (removes special characters)  
- 🎯 Clean and responsive UI  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript (ES6+)
