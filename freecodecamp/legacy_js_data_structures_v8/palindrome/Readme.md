# Palindrome Checker

## 📌 Project Overview
This project is a **Palindrome Checker** built with **HTML and JavaScript**.  
It checks whether a given word or phrase is a palindrome — meaning it reads the same forwards and backwards **after ignoring punctuation, spaces, and letter case**.

This implementation is fully compliant with the **FreeCodeCamp Palindrome Checker project requirements**.

---

## ✅ What Is a Palindrome?
A palindrome is a word, phrase, number, or sequence of characters that reads the same backward as forward when:
- Case differences are ignored
- Spaces are ignored
- Punctuation and symbols are ignored

### Examples:
- `eye`
- `race car`
- `A man, a plan, a canal. Panama`
- `never odd or even`
