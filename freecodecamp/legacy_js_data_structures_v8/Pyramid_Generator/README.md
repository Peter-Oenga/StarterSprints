# **Pyramid Generator – Inverted & Standard (JavaScript)**

This project generates a centered pyramid pattern using JavaScript.  
It serves as a foundational exercise in algorithmic thinking, loops, string manipulation, and console-based rendering.

The script allows flexible configuration such as the number of rows, the character used to draw the pyramid, and the option to generate either a **normal pyramid** or an **inverted pyramid**.

---

## ⭐ **Overview**

This script dynamically builds a symmetrical pyramid of characters (`#` by default).  
Depending on the value of `inverted`, it will output:

- A **normal (upright) pyramid**
- An **inverted (upside-down) pyramid**

The pyramid is fully centered using space padding on both sides of each row.
